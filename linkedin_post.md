🚀 **Building an Enterprise-Grade Multi-Agent AI Policy Assistant**

Over the past few days, I’ve been building a robust, multi-agent RAG system designed to handle complex, multi-domain company policies (HR, IT, Expense, Security, Remote Work) with absolute precision. 

Building a simple RAG app is easy, but making it truly "enterprise-ready" with zero hallucinations and perfect context routing is a massive engineering challenge. 

Here is a look under the hood at how I solved this:

🧠 **Multi-Agent Graph Architecture (LangGraph)**
Instead of one massive, easily confused LLM prompt, the system relies on a choreographed graph of specialized agents:
- **Query Rewriter:** Maintains conversational memory to resolve ambiguous pronouns (e.g., rewriting "Does *it* apply to interns?" to "Does *internet reimbursement* apply to interns?").
- **Guardrails Node:** Blocks inappropriate or out-of-scope queries before they hit the LLMs.
- **Intent Router:** Dynamically routes the query to the correct Domain Specialist Agent. If a user asks a multi-topic question (e.g., *"How many sick leaves do I get, and is VPN mandatory?"*), the router splits the query and triggers the HR and Security agents simultaneously!
- **Synthesizer Agent:** Collates the insights from all triggered domain agents into a single, cohesive, and perfectly formatted response.

⚖️ **Rigorous Evaluation Pipeline (DeepEval & Ollama)**
You can't manage what you don't measure. I built a comprehensive, automated 50-question test suite containing everything from "happy paths" to complex edge cases and negative constraints. 
Using **DeepEval** backed by a local **Ollama** judge, the pipeline automatically scores the system on:
✅ **Contextual Relevancy:** Solved context dilution by implementing strict, double-newline (`\n\n`) chunking so the LLM only ever sees the exact rule being queried without noise.
✅ **Faithfulness:** Ensured the model never hallucinates answers for out-of-policy questions.
✅ **Answer Relevancy:** Fine-tuned the system to prevent unicode rendering bugs and ensure outputs are perfectly formatted.

📊 **Observability**
Integrated with **Phoenix** to trace every execution path, log token usage, and monitor retrieval quality in real-time.
